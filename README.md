# community-doubt-knowledge-platform

A Java-based community platform designed to help students ask questions, share knowledge, and resolve academic doubts through collaborative discussions.

##  Project Overview

Students often face doubts while preparing for exams, assignments, and technical subjects. This platform provides a centralized space where students can post their questions, view answers from other students, update their responses, and manage resolved or irrelevant discussions.

The platform focuses on three main modules:

- **Question Posting**
- **Answer Management**
- **Moderation**

##  Key Features

 1.**Question Posting**
- Create and post questions.
- View questions posted by the community.
- Update questions.
- Delete or mark questions as resolved.

 2.**Answer Management**
- Add answers to questions.
- View answers.
- Update answers.
- Delete answers when required.

 3.** Moderation**
- Monitor community discussions.
- Remove irrelevant or inappropriate content.
- Manage resolved discussions.
- Maintain the quality of the platform.
